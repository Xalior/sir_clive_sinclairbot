BOT_TOKEN
=========
Discord Application Token

OPENAI_TOKEN
============
OpenAI compatible API Access Token

CACHE_URL
=========
Redis URL, in this format:
    redis://host:6379/dbid

OIDC_PROVIDER_URL
=================
URL of the OpenID Connect provider. At startup the bot reads the
provider's configuration from this URL.

OIDC_CLIENT_ID
==============
Client ID of this bot at the OpenID Connect provider.

OIDC_CLIENT_SECRET
==================
Client secret for OIDC_CLIENT_ID.

HOSTNAME
========
Public hostname of the bot, without https://. The bot uses it in the
OIDC callback URL (https://HOSTNAME/callback), in the links it sends to
users, and as the prefix of every Redis key.

SESSION_SECRET
==============
Secret that signs the web session cookie.

RELAY_SIGNING_KEY
=================
HMAC signing key for the relay plugin (org.xalior.relay).
Required. The bot does not start without it.
To rotate it, edit .env and restart the bot. Senders must use the same value.

RELAY_CLOCK_SKEW
================
Clock-skew tolerance window for relay HMAC requests, in seconds.
Optional. The default is 30. The bot rejects requests with a timestamp
outside ± this window.

ANTHROPIC_API_KEY
=================
Claude API key for the Claude chatbot plugin (org.xalior.claudebot).
The plugin requires ANTHROPIC_API_KEY or CLAUDE_CODE_OAUTH_TOKEN. If
neither is set, the bot does not start. If both are set, Claude Code uses
ANTHROPIC_API_KEY. Public and company instances must use this key.

CLAUDE_CODE_OAUTH_TOKEN
=======================
Claude subscription token for org.xalior.claudebot, made with
`claude setup-token` (Pro, Max, Team or Enterprise plan; valid for one
year). For one subscriber's own use only. See
https://code.claude.com/docs/en/legal-and-compliance

CLAUDEBOT_SYSTEM_PROMPT
=======================
Persona text for org.xalior.claudebot.
Optional. When set, it replaces the plugin's default persona. Applies to
new conversation threads only.
