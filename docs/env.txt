BOT_TOKEN
=========
Discord Application Token

OPENAI_TOKEN
============
OpenAI compatible API Access Token

CACHE_URL
=========
REDIS URL - in the following format:
    redis://host:6379/dbid

RELAY_SIGNING_KEY
=================
HMAC signing key for the relay plugin (org.xalior.relay).
Required — bot will refuse to start without it.
Rotate by editing .env and restarting; senders must use the same value.

RELAY_CLOCK_SKEW
================
Clock-skew tolerance window for relay HMAC requests, in seconds.
Optional — defaults to 30. Requests with timestamps outside ±this
window are rejected.

ANTHROPIC_API_KEY
=================
Claude API key for the Claude chatbot plugin (org.xalior.claudebot).
The plugin requires ANTHROPIC_API_KEY or CLAUDE_CODE_OAUTH_TOKEN; the bot
will refuse to start with neither set. If both are set, Claude Code uses
ANTHROPIC_API_KEY. Public and company instances must use this key.

CLAUDE_CODE_OAUTH_TOKEN
=======================
Claude subscription token for org.xalior.claudebot, made with
`claude setup-token` (Pro, Max, Team or Enterprise plan; valid for one
year). For one subscriber's own use only. See
https://code.claude.com/docs/en/legal-and-compliance

CLAUDEBOT_SYSTEM_PROMPT
=======================
Persona text for org.xalior.claudebot.
Optional. When set, it replaces the plugin's default persona. Applies to
new conversation threads only.
